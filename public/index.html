Mi Aplicación Web

Una aplicación web sencilla con frontend en HTML/CSS/JS y backend en Node.js.

Sobre esta aplicación

Esta aplicación sirve como punto de partida para construir un proyecto web completo con frontend y backend.

Instrucciones

  1. Instala las dependencias: npm install
  2. Inicia el servidor: npm start
  3. Abre http://localhost:3000 en tu navegador
